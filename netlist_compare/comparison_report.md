## 二、真实差异明细

### 2.1 B12_HOSTIO（3类差异）

1. **缺 13 只电容**: `C10001`–`C10013`（12只在+5V↔GND，`C10011` 接 RESET_RAW↔GND）。
2. **LED 极性相反（D10001–D10007，7只）** — 双方都存在的元件，引脚连接互换：
   - KiCad：pin1→GND，pin2→LED_x 信号（LED_PWR / LED_BUSY / LED_DONE / LED_ERROR / LED_IMAGE_READY / LED_MODEL_READY / LED_RESULT_VALID）
   - 嘉立创：pin1→LED_x 信号，pin2→GND
   - 封装同为 `LED-TH_BD5.0-P2.54-FD`，焊盘1/2对调 = 实板LED反接。
3. **X10001 晶振（8MHz 有源）引脚编号不同**：
   - KiCad 符号：pin1,2→GND，pin3→OSC_OUT，pin4→+5V
   - 嘉立创符号：pin1,4→GND，pin5→OSC_OUT，pin8→+5V（DIP-8金属壳标准编号，封装 `OSC-TH_4P-L12.7-W12.7-P7.62-BL-1`）
   - 若两侧封装焊盘映射一致（KiCad 的 3/4 对应物理 5/8 脚）则实板等效；但网表层不一致，需人工确认封装。

### 2.2 全部缺失的去耦电容（260 + 6 只，嘉立创侧一个都没有）

嘉立创全部14份网表中 **0 只电容**；KiCad 侧 260 只（B01–B12）+ LUT子图 6 只，全部为缺失项：

| 板 | 缺失元件 |
|----|----------|
| B01 | C1001–C1027（27） |
| B02 | C2001–C2011（11） |
| B03 | C4001–C4048（48） |
| B05 | C5001–C5045 + C13001（46） |
| B07 | C5101–C5145 + C13101（46） |
| B10 | C6001–C6045 + C13201–C13205（50） |
| B11 | C12001–C12014 + C12501–C12505（19） |
| B12 | C10001–C10013（13） |
| B13(LUT) | C11001–C11006（6） |

除 C10011（RESET_RAW）外全部跨接 +5V↔GND。**注意**：嘉立创网表导出不会漏掉 "Convert to PCB = yes" 的元件（TP/SW/LED模块均正常导出），故判定这些电容不在嘉立创工程网表中。若需保留去耦电容，需在嘉立创工程中补回或确认其被有意省略。

## 三、已忽略项（按用户要求）

1. **嘉立创LED模块**：每板 LED+三极管(Q)+电阻(R) 指示灯组合，共 1540 只：B01×28, B02×84, B03×40, B04×96, B05×248, B06×96, B07×248, B08×100, B09×100, B10×280, B11×100, B12×120，外加独立LED板 B00_BASIC_LED（LED1/Q1/R1/R2）。已验证：剔除后无任何残留引脚差异（即LED模块均为被动挂接，未改动原有信号连接）。
2. **悬空网络命名怪癖（非差异）**：B03 的10个悬空引脚网络，嘉立创网名引用了改动前的旧位号（如 `UNCONNECTED-(U4038A-...)` 实际含引脚 U4030-6，对应KiCad `unconnected-(U4030A-...)`）。两侧引脚与连接完全相同，仅名字不同（KiCad侧位号重编号 U4038→U4030，见 `CHANGES_MEM_BOOT_FOR_JLC.md`）。

## 四、对比方法与可复现性

- KiCad 网表：`kicad-cli sch export netlist` → `kicad_net.net`（导出时有一条批注警告，不影响网表生成）。
- 嘉立创网表：EDA bridge API 逐板导出 Protel2（`jlc_netlists/BXX_*.net`，与EDA界面"导出网表-Protel"等价）。
- 对比脚本：`scripts/compare.py`（KiCad s-expression 解析 `scripts/sexpr.py`），明细数据 `report_raw.json`。
- 每板 KiCad 视图 = 该板所含子图（BXX_Conn + S系列）元件在全局网表中引脚的投影；跨板网络按板内引脚裁剪后与嘉立创板级网表比对。

## 五、剔除电容问题后的完整差异清单（最终结论）

若不考虑全部电容缺失问题（B01–B13 共 260+6 只，见第 2.2 节），两份网表的全部差异如下：

### A. 真实连接性差异 —— 仅 B12_HOSTIO，共 2 处

1. **D10001–D10007 七只LED极性相反**（两边都存在的元件，引脚互换）：

   | 网络 | KiCad | 嘉立创 |
   |------|-------|--------|
   | LED_PWR | D10001 pin2=信号, pin1=GND | D10001 pin1=信号, pin2=GND |
   | LED_BUSY / LED_DONE / LED_ERROR / LED_IMAGE_READY / LED_MODEL_READY / LED_RESULT_VALID | 同上模式（pin2=信号, pin1=GND） | 同上模式（pin1=信号, pin2=GND） |

   封装两侧同为 `LED-TH_BD5.0-P2.54-FD` → 实板LED将反接，需修正一侧。

2. **X10001（8MHz 有源晶振）引脚映射不同**：
   - KiCad 符号（4脚编号）：pin1=GND, pin2=GND, pin3=OSC_OUT, pin4=+5V
   - 嘉立创符号（DIP-8金属壳编号）：pin1=GND, pin4=GND, pin5=OSC_OUT, pin8=+5V
   - 封装 `OSC-TH_4P-L12.7-W12.7-P7.62-BL-1`。若 KiCad 封装焊盘把 3→物理5脚、4→物理8脚 映射则实板等效；网表层不一致，需人工核对封装。

### B. 命名/表示差异 —— 仅 B03_MEMORY，连接性完全相同

1. **10 个悬空网络名引用旧位号**（KiCad 已重编号 U4038→U4030 等，嘉立创网名仍是旧号，但所含引脚完全相同）：
   `unconnected-(U4020/4023/4025/4026/4030A/4030B-…)` ↔ `UNCONNECTED-(U4028/4031/4033/4034/4038A/4038B-…)`
2. **8 个悬空引脚嘉立创网表未列出**：U4021-7/9/10/11、U4022-12/13/14/15（KiCad 导出为单脚 `unconnected-(…)` 网络；嘉立创因这些脚无 no-connect 标记而不导出）。两侧均为悬空，无连接差异。

### C. 工程结构差异

- **B13_LUT_REF**：KiCad 顶层未挂载 `S_LUT_Mult_1` 子图（仅以独立文件存在）；嘉立创侧为独立板。板级网表剔除电容后完全一致。
- **B00_BASIC_LED**：嘉立创独有 LED 实验板（用户指示忽略）。

### D. 其余 10 块板

B01、B02、B04、B05、B06、B07、B08、B09、B10、B11 —— 剔除电容差异后**全部完全一致**（网络名、引脚、连接零差异）。
